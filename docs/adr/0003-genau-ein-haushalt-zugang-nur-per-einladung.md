# Genau ein Haushalt, Zugang nur per Einladung

Das System verwaltet genau einen Haushalt. Es gibt keine Mandantentrennung, und alle Nutzer sehen und bearbeiten alle Items. Es gibt auch keine offene Registrierung: Nutzer melden sich mit E-Mail und Passwort an und kommen nur per Einladung durch einen bestehenden Nutzer hinzu. Das hält Berechtigungen und das Datenmodell einfach. Mehrere Haushalte nachzurüsten würde bedeuten, jede Tabelle und jede Abfrage um eine Haushalts-Zuordnung zu erweitern. Das nehmen wir bewusst in Kauf.
