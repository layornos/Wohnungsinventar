# Hinweis bei neuer Version

Status: erledigt
Typ: Feature

## Was

Die installierte App lädt neue Versionen erst, wenn man sie ganz schließt. Erkennt sie eine neue Version (Service Worker), zeigt sie einen unaufdringlichen Hinweis „Neue Version verfügbar“ mit „Neu laden“. Beim Öffnen und beim Zurückkehren in die App sucht sie nach Updates.

## Fertig, wenn

- [ ] Nach einem Deploy erscheint der Hinweis in der offenen App, und „Neu laden“ zeigt die neue Version, ohne die App zu schließen.
